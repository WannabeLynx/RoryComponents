# Welcome to RoryComponents

This is a living style guide and component workshop for the RoryComponents library.

## About This Library

RoryComponents is a collection of reusable Vue 3 components built with TypeScript and styled with Tailwind CSS. It's designed to provide a consistent, modern, and accessible set of UI building blocks for your applications.

## How to Use This Storybook

*   **Browse Components**: Use the sidebar on the left to navigate through the available components, which are organized by Atomic Design principles (Atoms, Molecules, Organisms).
*   **Interact with Controls**: Select a component to see its story. Use the "Controls" tab in the addon panel at the bottom to dynamically change its props and see how it behaves in real-time.
*   **View Documentation**: The "Docs" tab provides detailed information about each component's props, events, and slots.

## For Developers

To learn more about how to install and use these components in your own project, please see the [project README on GitHub](https://github.com/your-username/rory-components).
